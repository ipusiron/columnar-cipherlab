📚 縦列転置式暗号とは

基本原理

縦列転置式暗号（Columnar Transposition Cipher）は、平文の文字の順序を体系的に並べ替える転置式暗号の一種です。

  • 平文を横方向（行方向）にマトリクスへ書き込む
  • 鍵に基づいて列を並べ替える
  • 縦方向（列方向）に読み出して暗号文を生成

例：キーワード "KEY" での暗号化

平文: HELLO WORLD
鍵順: K=2, E=1, Y=3

マトリクス（書き込み）:
  K E Y
  2 1 3
  -------
  H E L
  L O W
  O R L
  D X X  (Xはパディング)

列の並べ替え（鍵順で）:
  E K Y
  1 2 3
  -------
  E H L
  O L W
  R O L
  X D X

暗号文（縦読み）: EORX HLOD LWLX

暗号の種類と特徴

①完全／不完全

完全モード：パディング文字で長方形にする

不完全モード：最終行が欠けたまま処理

②鍵の種類

キーワード：単語をアルファベット順で数値化

数列：直接数値で列順を指定（例: 3,1,4,2）

Myszkowski式：キーワードの同じ文字の列をまとめて、行ごとに左から読む

③二重転置

縦列を2回：縦列転置を2つの鍵で続けて行う

行と列：正方形の行と列を同じ鍵で並べ替える（ニヒリスト転置）

縦列を2回の方式は「二重転置」タブで試せます。

④経路式（ルート式）

斜め読み出し：対角線方向に読む

らせん読み出し：渦巻き状に読む

転置式暗号の歴史と背景

古代〜中世

スパルタのスキュタレー暗号など、初期の転置式暗号が登場。巻物を棒に巻きつけて文字を読む方式。

1880年代 - ロシアのニヒリスト

帝政ロシアの革命家たちが、ポリュビオス方陣を使う換字式の「ニヒリスト暗号」を使いました。転置式の「ニヒリスト転置」（正方形の行と列を同じ鍵で並べ替える）は、ゲインズの教科書『Cryptanalysis』（1939年）に載っている方式です。

第一次世界大戦

ドイツ軍が二重転置を使いました。鍵をあまり替えなかったため、フランスに繰り返し解読されました（フランス側の呼び名はÜbchi）。

第二次世界大戦

機械式の暗号機が主流になった一方で、二重転置は手作業の暗号として、オランダのレジスタンス、フランスのマキ、イギリスの特殊作戦執行部（SOE）などで使われました。

暗号学的特性

セキュリティ分析

  • 拡散（Diffusion）：文字の位置を分散させる効果あり
  • 混同（Confusion）：なし（文字の置換は行わない）
  • 文字の頻度：平文と同じまま（頻度を数えると、換字式ではなく転置式だと見分けられる）

攻撃手法

  • 総当たり攻撃：鍵長nに対してn!通りの並べ方を試す（n=8で40,320通り）
  • 2文字の組の頻度：列を並べ替え、THやHEのような自然な2文字の組が多くなる並びを探す
  • アナグラム攻撃：推測した単語が入るように列を並べ、鍵を推定する（同じ鍵の暗号文が複数あれば、まとめて並べ替える多重アナグラム法が使える）
⚠️ 現代での使用について

縦列転置式暗号は教育目的や暗号学の基礎理解には優れていますが、現代のセキュリティ要件を満たしません。実用的な暗号化にはAESなどの現代暗号を使用してください。

他の古典暗号との比較

暗号方式 種類 操作 特徴
縦列転置式 転置 文字の並べ替え 文字頻度は保存される
シーザー暗号 換字 文字のシフト 単純な頻度分析で破れる
ヴィジュネル暗号 換字 複数のシフト 多表式。鍵の長さがわかると頻度分析で破れる
レールフェンス暗号 転置 ジグザグ配置 レールの数が鍵のジグザグ転置
プレイフェア暗号 換字 2文字組の置換 1文字の頻度は隠れるが、2文字の組の頻度で破れる

実装のポイント

暗号化アルゴリズム

  1. 平文の前処理（スペース除去、大文字化など）
  2. 鍵から列順序を決定（キーワード→数値変換）
  3. マトリクスへの行方向書き込み
  4. 必要に応じてパディング追加
  5. 鍵順での列の並べ替え
  6. 列方向での読み出し

復号アルゴリズム

  1. 暗号文の長さと鍵から行数を計算（行数 = ceil(暗号文長 ÷ 列数)）
  2. 各列の高さを決定（不完全モードでは注意）
  3. 鍵順にしたがって暗号文を列に配分
  4. 元の列順序に戻す
  5. 行方向で読み出して平文を復元
  6. パディングの除去（完全モードの場合）
📘 ceil関数について
ceil（シーリング）は天井関数とも呼ばれ、小数点以下を切り上げる数学関数です。
例：ceil(3.2) = 4、ceil(5.0) = 5、ceil(2.1) = 3
復号時の行数計算で使用し、暗号文がマトリクスに完全に収まるよう必要最小限の行数を求めます。

埋字の曖昧さ

完全モードでは、最終行の空きを埋字で埋めます。埋字は最大でも「列数−1」文字ですが、平文がもともと埋字と同じ文字で終わっていると、暗号文だけでは区別できません。

例：キーワード "KEY"・埋字 X

平文 "FO"  → F O X(埋字) → 暗号文 OFX
平文 "FOX" → F O X(平文) → 暗号文 OFX

どちらも同じ暗号文になる。
復号の「埋字を自動除去」は末尾のXを埋字とみなすので、結果は "FO"。
  • 本ツールは、平文の最後の文字が埋字と同じときに、暗号化の時点で知らせる
  • 復号では除いた埋字の数を表示し、表の中で埋字のセルを色分けする
  • 実際の運用では、平文に出にくい文字や、意味のない文字（ヌル）を混ぜて埋めることがある

Basic principle

The columnar transposition cipher is a transposition cipher: it rearranges the order of the plaintext letters in a systematic way.

  • Write the plaintext into a matrix row by row
  • Reorder the columns according to the key
  • Read the ciphertext column by column

Example: encrypting with the keyword "KEY"

Plaintext: HELLO WORLD
Key order: K=2, E=1, Y=3

Matrix (written row by row):
  K E Y
  2 1 3
  -------
  H E L
  L O W
  O R L
  D X X  (X is padding)

Columns reordered by the key:
  E K Y
  1 2 3
  -------
  E H L
  O L W
  R O L
  X D X

Ciphertext (read down the columns): EORX HLOD LWLX

Types and features

1. Complete / incomplete

Complete: pad the last row to make a rectangle

Incomplete: leave the last row short

2. Kinds of keys

Keyword: number the letters of a word in alphabetical order

Number sequence: give the column order directly (e.g. 3,1,4,2)

Myszkowski: read columns with the same keyword letter together, row by row from the left

3. Double transposition

Two columnar passes: apply columnar transposition with two keys in a row

Rows and columns: reorder both the rows and the columns of a square with the same key (Nihilist transposition)

You can try the two-pass method in the Double transposition tab.

4. Route ciphers

Diagonal reading: read along the diagonals

Spiral reading: read in a spiral

History

Antiquity to the Middle Ages

Early transposition ciphers such as the Spartan scytale, where a strip is wound around a rod and the text is read along it.

1880s - Russian Nihilists

Revolutionaries in Tsarist Russia used the "Nihilist cipher", a substitution cipher based on a Polybius square. The transposition known as the "Nihilist transposition" (reordering both the rows and the columns of a square with the same key) is described in Gaines' textbook Cryptanalysis (1939).

World War I

The German army used double transposition. Because the keys were changed infrequently, the French solved it regularly (they called it Übchi).

World War II

While cipher machines became mainstream, double transposition was used as a hand cipher by the Dutch resistance, the French Maquis and the British Special Operations Executive (SOE), among others.

Cryptographic properties

Security analysis

  • Diffusion: spreads the positions of the letters
  • Confusion: none (no letter is substituted)
  • Letter frequencies: the same as in the plaintext (counting them tells a transposition from a substitution)

Attacks

  • Brute force: try all n! column orders for a key length n (40,320 orders for n=8)
  • Letter pair frequencies: reorder the columns to find the arrangement with the most natural pairs such as TH and HE
  • Anagramming: arrange the columns so that a guessed word appears, and infer the key (with several ciphertexts under the same key, they can be rearranged together: multiple anagramming)
⚠️ About modern use

The columnar transposition cipher is good for education and for learning the basics of cryptography, but it does not meet modern security requirements. Use modern ciphers such as AES for real encryption.

Comparison with other classical ciphers

Cipher Type Operation Notes
Columnar transposition Transposition Reorders letters Letter frequencies are preserved
Caesar cipher Substitution Shifts letters Broken by simple frequency analysis
Vigenère cipher Substitution Several shifts Polyalphabetic. Broken by frequency analysis once the key length is known
Rail fence cipher Transposition Zigzag placement A zigzag transposition whose key is the number of rails
Playfair cipher Substitution Substitutes letter pairs Hides single-letter frequencies but is broken by pair frequencies

Implementation notes

Encryption

  1. Preprocess the plaintext (remove spaces, convert to uppercase, and so on)
  2. Determine the column order from the key (keyword to numbers)
  3. Write the text into the matrix row by row
  4. Add padding if needed
  5. Reorder the columns by the key
  6. Read column by column

Decryption

  1. Compute the number of rows from the ciphertext length and the key (rows = ceil(length ÷ columns))
  2. Determine the height of each column (take care in incomplete mode)
  3. Distribute the ciphertext to the columns in key order
  4. Put the columns back in their original order
  5. Read row by row to recover the plaintext
  6. Remove the padding (in complete mode)
📘 About ceil
ceil (the ceiling function) rounds a number up to the next integer.
Examples: ceil(3.2) = 4, ceil(5.0) = 5, ceil(2.1) = 3
It is used when decrypting to find the smallest number of rows that holds the whole ciphertext.

Padding ambiguity

In complete mode the empty cells of the last row are filled with the padding letter. There are at most (columns − 1) padding letters, but if the plaintext itself ends with the padding letter, the ciphertext alone cannot tell them apart.

Example: keyword "KEY", padding X

Plaintext "FO"  → F O X(padding)   → ciphertext OFX
Plaintext "FOX" → F O X(plaintext) → ciphertext OFX

Both give the same ciphertext.
"Remove padding automatically" treats the final X as padding, so the result is "FO".
  • This tool warns at encryption time when the last plaintext letter is the same as the padding letter
  • When decrypting, it shows how many padding letters were removed and colors those cells in the matrix
  • In practice, padding is sometimes made of letters that rarely end a message, or of meaningless letters (nulls)

  1. 「暗号化」タブで平文を入力（「サンプル設定」から選ぶと、練習用の平文と鍵が入る）

  4. 「復号実行」ボタンで復号を実行

🧩 二重転置・解読ラボ

二重転置タブ

1段目の鍵で縦列転置した暗号文を、2段目の鍵でもう一度縦列転置します。鍵はキーワードでも数列でも入れられます。埋字は使いません（不完全モード）。「Wikipediaの例」で既知の例を試せます。

解読ラボタブ

  • 鍵のわからない暗号文の長さ、完全モードなら考えられる鍵長、転置式か換字式かの目安（英字の頻度のカイ二乗）を表示する
  • 総当たり：鍵長2〜8の列の並べ方をすべて試し、英字の隣り合う2文字の組が英語らしい順に候補を出す。暗号文は1,000文字まで
  • 既知の単語を入れると、その単語を含む候補だけを残す
  • 作業台：列を左右に入れ替えて、行に英語が読めるかを確かめる。候補の「作業台で見る」から開ける

共有リンク

暗号化タブの「問題として共有」は暗号文とモードだけ、「解答つきで共有」は鍵も含むリンクを作ります。平文は含めません。

🔑 鍵の種類

キーワード方式

英単語から列順序を自動生成します。アルファベット順で列に番号を割り当てます。

  • 例：「ZEBRAS」→ A=1, B=2, E=3, R=4, S=5, Z=6
  • 同じ文字がある場合は左側が優先されます
  • 例：「BALLOON」→ B=2, A=1, L=3, L=4, O=6, O=7, N=5
  • 大文字と小文字は区別しない（zebras と ZEBRAS は同じ鍵）
  • 「Myszkowski式」をオンにすると、同じ文字の列をまとめて行ごとに読む（例：「TOMATO」→ 4 3 2 1 4 3）

数列方式

列を読み出す順序を数字で直接指定します。

  • 1から列数までの数を1回ずつ使う
  • 空白・カンマ・読点で区切る。区切らずに「31425」のように書けるのは9列まで
  • 例：「3 1 4 2 5」「2,4,1,3,5」

⚙️ 設定オプション

完全モード

マトリクスを長方形にするため、不足分をパディング文字（通常は「X」）で埋めます。完全モードの暗号文は、長さが列数の倍数になります。

復号の「埋字を自動除去」は、末尾の埋字を最大「列数−1」文字まで除きます。平文がもともと埋字と同じ文字で終わっていると区別できません（座学タブの「埋字の曖昧さ」）。

空白の無視（復号）

「EORX HLOD」のように区切った暗号文は、空白・改行を除いてから復号します。空白も暗号化した暗号文では、チェックを外してください（暗号化タブから同期すると自動で外れる）。

整形オプション

  • スペース削除：平文からスペースを除去
  • 記号削除：句読点・記号・アンダースコアを除去（文字と数字は残す。日本語も残る）
  • 英大文字化：アルファベットを大文字に統一

🎯 便利な機能

  • サンプル設定：暗号化タブのサンプルボタンで学習用データを自動設定
  • 同期機能：復号タブで暗号化結果を自動取得
  • マトリクス可視化：暗号化・復号過程をグリッドで確認
  • ハイライト表示：マトリクスの列（暗号化）や行（復号）と、文字の対応を色で示す。鍵順・行番号のボタンで固定できる
  • コピー機能：結果をワンクリックでクリップボードにコピー
  • 座学タブ：暗号の歴史や理論を学習
  • 言語：右上の「EN／日本語」ボタンで、画面を英語と日本語で切り替える

🔒 セキュリティについて

⚠️ 重要な注意事項

縦列転置式暗号は教育目的や暗号学の基礎理解には優れていますが、現代のセキュリティ要件を満たしません。実用的な暗号化にはAESなどの現代暗号を使用してください。

💡 ヒントとコツ

  • 暗号化前に整形オプションを確認してください
  • 復号時は暗号化時とまったく同じ設定を使用する必要があります
  • パディング文字は、平文の最後に来ない文字を選んでください
  • マトリクスの行や列にマウスを合わせると、対応する文字がハイライトされます
  • 鍵の欄でEnter、平文・暗号文の欄でCtrl+Enter（MacはCmd+Enter）を押しても実行できます
  • 入力や設定を変えると、表示中の結果が古いことを知らせます。もう一度実行すると更新されます

🚀 Basic use

Encrypt

  1. Enter the plaintext in the Encrypt tab (choose from "Samples" to fill in a practice plaintext and key)
  2. Choose the key type (keyword or number sequence)
  3. Keyword example: "ZEBRAS"; number sequence example: "3 1 4 2 5"
  4. Choose complete mode (with padding) or incomplete mode
  5. Press "Encrypt"
  6. The matrix and the ciphertext are shown

Decrypt

  1. Enter the ciphertext in the Decrypt tab
  2. Use the same key and mode as for encryption
  3. "Use the Encrypt tab result" copies the ciphertext and settings at once
  4. Press "Decrypt"
  5. The decryption matrix and the plaintext are shown

🧩 Double transposition and cryptanalysis lab

Double transposition tab

Transposes the text with the first key, then transposes that ciphertext again with the second key. Keys can be keywords or number sequences. No padding is used (incomplete mode). "Wikipedia example" fills in a known example.

Cryptanalysis lab tab

  • Shows the length of a ciphertext with an unknown key, the possible key lengths in complete mode, and a hint whether it is a transposition or a substitution (chi-squared of the letter frequencies)
  • Brute force: tries every column order for key lengths 2 to 8 and lists the candidates with the most English-like letter pairs first. Ciphertexts up to 1,000 characters
  • A known word keeps only the candidates that contain it
  • Workbench: move columns left and right and check whether the rows read as English. Open it from a candidate with "Open in workbench"

Share links

In the Encrypt tab, "Share as a puzzle" makes a link with only the ciphertext and the mode, and "Share with answer" also includes the key. The plaintext is never included.

🔑 Kinds of keys

Keyword

The column order is built from a word: the letters are numbered in alphabetical order.

  • Example: "ZEBRAS" → A=1, B=2, E=3, R=4, S=5, Z=6
  • Repeated letters are numbered from the left
  • Example: "BALLOON" → B=2, A=1, L=3, L=4, O=6, O=7, N=5
  • Case does not matter (zebras and ZEBRAS are the same key)
  • With "Myszkowski" on, columns with the same letter are read together, row by row (example: "TOMATO" → 4 3 2 1 4 3)

Number sequence

Gives the order in which the columns are read.

  • Use each number from 1 to the column count once
  • Separate with spaces or commas. Without separators (such as "31425") up to 9 columns
  • Examples: "3 1 4 2 5", "2,4,1,3,5"

⚙️ Options

Complete mode

Fills the rest of the matrix with the padding letter (usually "X") to make a rectangle. In complete mode the ciphertext length is a multiple of the column count.

"Remove padding automatically" removes up to (columns − 1) padding letters from the end. If the plaintext itself ended with the padding letter, the two cannot be told apart (see "Padding ambiguity" in the Learn tab).

Ignoring spaces (decryption)

Ciphertext split into groups such as "EORX HLOD" is decrypted after removing spaces and line breaks. Uncheck this if spaces were encrypted too (it is unchecked automatically when copying from the Encrypt tab).

Formatting

  • Remove spaces: removes spaces from the plaintext
  • Remove symbols: removes punctuation, symbols and underscores (letters and digits are kept, including Japanese)
  • Uppercase: converts letters to uppercase

🎯 Handy features

  • Samples: fill in learning data from the Samples button in the Encrypt tab
  • Sync: take the encryption result into the Decrypt tab
  • Matrix view: follow encryption and decryption on a grid
  • Highlight: shows which column (encryption) or row (decryption) each letter belongs to. Fix the highlight with the key-order and row-number buttons
  • Copy: copy the result to the clipboard with one click
  • Learn tab: history and theory of the cipher
  • Language: switch the screen between English and Japanese with the "EN / 日本語" button at the top right

🔒 Security

⚠️ Important

The columnar transposition cipher is good for education and for learning the basics of cryptography, but it does not meet modern security requirements. Use modern ciphers such as AES for real encryption.

💡 Tips

  • Check the formatting options before encrypting
  • Decryption needs exactly the same settings as encryption
  • Choose a padding letter that will not end the plaintext
  • Hover over a row or column of the matrix to highlight the matching letters
  • Press Enter in a key field, or Ctrl+Enter (Cmd+Enter on a Mac) in the plaintext or ciphertext field, to run
  • When you change an input or setting, the tool shows that the displayed result is out of date. Run again to update it
